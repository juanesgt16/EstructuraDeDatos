# Vector (arreglo dinámico)

**Qué es:** arreglo que crece solo. Cuando se llena, crea uno el doble de grande y copia los datos.

**Operaciones:** `agregar`, `obtener`, `establecer`, `eliminar`, `tamano`.

**Cuándo usarlo:** cuando se necesita acceso rápido por posición y la cantidad de datos cambia. En Java equivale a `ArrayList` y a la clase `Vector` (esta última es sincronizada, por eso más lenta).

## Archivos
- `VectorDinamico.java`: implementación propia.
- `PruebaVector.java`: ejemplo de uso (lista de notas).
