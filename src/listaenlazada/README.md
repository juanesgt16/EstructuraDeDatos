# Lista enlazada

**Qué es:** secuencia de nodos; cada nodo guarda su dato y una referencia al siguiente.

**Operaciones:** `agregarAlInicio`, `agregarAlFinal`, `contiene`, `eliminar`, `tamano`.

**Cuándo usarla:** cuando se insertan y borran elementos con frecuencia y no importa acceder por posición.

## Archivos
- `ListaEnlazada.java`: implementación propia.
- `PruebaListaEnlazada.java`: ejemplo de uso (lista de tareas).
